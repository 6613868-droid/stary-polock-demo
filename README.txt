«Старый Полоцк» — демонстрационный дизайн-концепт сайта кафе
=============================================================

Что это
-------
Одностраничный сайт-концепт для коммерческого предложения владельцу кафе
«Старый Полоцк» (Полоцк, просп. Франциска Скорины, 2). НЕ официальный сайт.
Чистый HTML/CSS/JS, один файл index.html + папка images — ничего собирать не нужно.

Как открыть
-----------
Просто открыть index.html в браузере, либо (лучше) через локальный сервер:
    python -m http.server 8015
и зайти на http://127.0.0.1:8015

Как заменить фото на реальные
-----------------------------
Все фотографии лежат в папке images/ и подключаются по именам.
Достаточно положить свои файлы с теми же именами (или поменять пути в index.html):

  interior-1.jpg  — вертикальный кадр зала (первый экран + галерея + «Атмосфера»)
  bread-1.jpg     — вертикальный натюрморт стола («Атмосфера» + галерея)
  interior-3.jpg  — квадратный кадр зала (галерея)
  polock-sofia-2.jpg — вид на Софиевский собор (галерея, «Старый город»)
  polock-sofia-4.jpg — Софийский собор из парка (блок «Интерлюдия — город»)

Рекомендации: JPEG, ширина 1200–1600 px, качество ~80.
Тёплый цветокор в CSS (фильтр sepia) настроен так, что и обычные фото впишутся.
После замены убрать из футера строку про «временные референсы».

Что поправить перед показом клиенту
-----------------------------------
1. Телефон +375 33 396-81-11 взят из открытой карточки — подтвердить у владельца.
2. Часы работы сейчас «Уточняйте по телефону» — заменить на реальные.
3. Меню — демонстрационная структура категорий без блюд и цен (по ТЗ).
   Заполняется списком владельца: скопировать любой <li class="menu__row"> и
   заменить название/подпись.
4. Ссылка на Яндекс Карты уже ведёт на адрес — при необходимости заменить
   на точную карточку заведения.

Публикация
----------
Папка готова к загрузке на GitHub Pages через deploy.cjs:
    node deploy.cjs stary-polock-demo stary-polock-demo
Ссылка будет вида https://6613868-droid.github.io/stary-polock-demo/
После деплоя подождать ~5 минут (обновление CDN) и проверить ссылку инкогнито.
